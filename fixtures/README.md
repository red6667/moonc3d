# Synthetic C3D fixtures

Generated by `python scripts/differential.py --emit-fixtures`, using py-c3d at the immutable commit in `scripts/reference-lock.json` (MIT). No human capture data is included. Points: heel/toe; analog: Fx/EMG; 3 point frames starting at 7; 100 Hz/200 Hz; residual scale 0.5; nonidentity signed calibration. Invalid marker at frame 8.

Intel files are produced by py-c3d. MIPS cases are deterministic endian conversions in the independent Python harness; these are not recordings from MIPS hardware. The harness checks both MoonC3D and py-c3d readers, then verifies the canonical MoonC3D rewrite with py-c3d. Float32 tolerance is absolute 1e-6 on valid coordinates/residuals, masks and calibrated analog samples. Invalid XYZ values are unspecified; residual -1 is checked instead. Hex encoding avoids opaque binary assets and is byte-exact.
